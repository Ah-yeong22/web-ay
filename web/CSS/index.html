홍길동 / Front-End Developer

HTML/CSS 학습 중 · 사용자 친화적인 UI에 관심 있음

사용자가 보기 편한 화면을 만드는 것에 관심이 많습니다. 시맨틱 태그를 활용하여 구조를 명확하게 작성하려고 노력하고 있으며, HTML과 CSS를 이용한 다양한 레이아웃과 스타일링을 연습하고 있습니다.

기술 스택 / 사용 가능 기술

HTML

  • 시맨틱 태그(header, nav, section, footer) 활용 가능
  • 이미지, 링크, 목록, 폼 요소 작성 가능
  • 웹 문서 구조를 체계적으로 설계 가능

CSS

  • Flexbox를 활용한 레이아웃 구성 가능
  • 배경, 테두리, 그림자, 텍스트 스타일 적용 가능
  • 반응형 웹 기초 및 화면 중앙 정렬 구현 가능

프로젝트

포트폴리오 페이지 만들기 2026.06 - 진행 중

HTML 시맨틱 태그와 CSS 스타일링을 활용하여 개인 포트폴리오 페이지를 제작하고 있습니다. Flexbox를 사용해 프로필 및 프로젝트 영역을 구성했습니다.

학원 수강생 관리 화면 기획 단계

학원에서 사용할 수 있는 수강생 등록 및 조회 화면을 구현할 예정입니다. HTML 폼 요소와 CSS 레이아웃을 적극적으로 활용할 계획입니다.
